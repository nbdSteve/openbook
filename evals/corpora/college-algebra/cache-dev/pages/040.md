SECTION 6.1 Exponential Functions 465 From Table 2 we can infer that for these two functions, exponential growth dwarfs linear growth. •	 Exponential growth refers to the original value from the range increases by the same percentage over equal increments found in the domain. •	 Linear growth refers to the original value from the range increases by the same amount over equal increments found in the domain. Apparently, the difference between “the same percentage” and “the same amount” is quite significant. For exponential growth, over equal increments, the constant multiplicative rate of change resulted in doubling the output whenever the input increased by one. For linear growth, the constant additive rate of change over equal increments resulted in adding 2 to the output whenever the input was increased by one. The general form of the exponential function is f(x) = abx , where a is any nonzero number, b is a positive real number not equal to 1. •	 If b > 1, the function grows at a rate proportional to its size. •	 If 0 < b < 1, the function decays at a rate proportional to its size.
