Determine whether a is positive or negative. If a is positive, the parabola has a minimum. If a is negative, the parabola has a maximum. 3. Determine the maximum or minimum value of the parabola, k. 4. If the parabola has a minimum, the range is given by f(x) ≥ k, or [k, ∞). If the parabola has a maximum, the range is given by f(x) ≤ k, or (−∞, k]. Example 4 Finding the Domain and Range of a Quadratic Function Find the domain and range of f(x) = −5x2 + 9x − 1.
